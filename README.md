# 가대 ZIP — 도면 연동형 캠퍼스 안내 지도

## 실행
압축을 풀고 `index.html`을 브라우저에서 엽니다. 별도 서버·라이브러리가 필요 없습니다.

## 이번 수정 범위
- 기존 지도 위치와 건물 1~22번 번호, 검색, 마스코트, 로고를 유지했습니다.
- `assets/floors/`에 29개 원본 도면을 WebP로 저장했습니다. 김수환관 2F/3F만 제공된 수정본을 사용했습니다.
- 이미지 안의 글꼴과 벽선은 다시 그리지 않았습니다. 원본 정보 보존을 위해 디스플레이 UI를 공통화했습니다.
- 도면 확대·축소, 새 탭 원본 보기, 반응형 팝업을 추가했습니다.
- 도면이 없는 건물은 임시 층 버튼을 띄우지 않습니다.
- 미래융합관은 현재 지도에서 대응 번호를 확정할 근거가 없어 23번을 임의 부여하지 않고 **목록에서만** 찾을 수 있도록 했습니다. 지도 위치가 확인되면 연결하세요.
- 김수환관·다솔관의 층별 안내표도 `층별 안내` 탭으로 제공합니다.

## 파일 구성
- `index.html`: 원본 사이트 + 도면 표시 UI
- `styles.css`: 원본 스타일 + 팝업 UI 스타일
- `app.js`: 원본 지도 좌표 + 실제 도면 경로 연결 및 확대 기능
- `assets/`: 기존 지도·로고·마스코트 이미지 (변경 없음)
- `assets/floors/`: WebP 층별 도면 29장

## 운영 전 확인
1. 김수환관 2F/3F는 이전 대화에서 만든 수정 이미지입니다. 강의실 번호와 방 배치가 원본과 일치하는지 확인이 필요합니다.
2. 학교의 현재 건물 명칭과 실 위치, 건물별 도면 정확성은 학교 자료와 최종 교차 검증하세요.
3. 미래융합관이 캠퍼스 지도상 어느 건물 번호인지 확인 후 `app.js`의 `directoryOnly` 설정을 조정하세요.
4. 원본은 사용자가 제공한 파일이며 시설 정보의 정확성은 보증되지 않습니다.

## 새 이미지 추가
`app.js`의 `floorPlans` 객체에 `{층: './assets/floors/파일.webp'}` 경로를 추가한 다음 해당 건물의 `planKey`를 지정합니다. 이미 존재하는 건물 위치를 바꿀 필요는 없습니다.
